# Capturas de las historias implementadas

Cada archivo PNG contiene únicamente el apartado indicado y puede abrirse directamente en el navegador o en un visor de imágenes.

- `us03-niveles-y-tecnicas.png` — niveles y técnicas de prueba.
- `us04-herramientas-de-calidad.png` — herramientas agrupadas por categoría.
- `us06-cascada.png`, `us06-modelo-en-v.png` y `us06-iterativo-incremental.png` — modelos tradicionales.
- `us09-diagrama-scrum-sprint.png`, `us09-flujo-kanban.png` y `us09-ciclo-xp.png` — esquemas ágiles.
- `us10-scrum-detalle.png` — responsabilidades, eventos, cronograma y artefactos Scrum.
